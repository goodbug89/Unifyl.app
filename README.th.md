## ภาพรวม

Unifyl คือโปรแกรมจัดการไฟล์แบบสองบานหน้าต่างสำหรับ macOS ที่รวมเครื่องมือระดับมืออาชีพเข้ากับ AI ในเครื่อง ไฟล์ของคุณไม่เคยออกจาก Mac

- **สองบานหน้าต่าง** — เลย์เอาต์เดี่ยว/คู่/สาม/แบ่งอิสระ แท็บ พื้นที่ทำงาน เทอร์มินัลในตัวต่อบานหน้าต่าง
- **ขับเคลื่อนด้วย AI** — ค้นหาเชิงความหมาย เปลี่ยนชื่อด้วย AI แท็กอัจฉริยะ ตรวจหาไฟล์ซ้ำ — ทั้งหมดทำงานในเครื่องบน Apple Neural Engine
- **รีโมตและคลาวด์** — FTP/SFTP/WebDAV/SMB/S3/Google Drive/Dropbox/OneDrive/Docker/Kubernetes
- **เครื่องมือระดับมืออาชีพมากกว่า 50 รายการ** — เปลี่ยนชื่อแบบกลุ่ม เปรียบเทียบข้อความ/ไบนารี/รูปภาพ ซิงค์ไดเรกทอรี รวม 3 ทาง แก้ไข EXIF เป็นกลุ่ม
- **ไฟล์บีบอัดเป็นโฟลเดอร์เสมือน** — ZIP/7z/TAR/GZ/BZ2/XZ/ZSTD/RAR (รวมการตรวจหาการเข้ารหัสของ ZIP CJK รุ่นเก่า)
- **คีย์บอร์ดมาก่อน** — แผงคำสั่ง การนำทางสไตล์ Vim ทางลัดกว่า 120 รายการที่ปรับเปลี่ยนได้
- **15 ภาษา**
- **เสริมความสามารถ CJK** (1.3.0): แตกไฟล์ `.alz` (`unalz` มาในตัว), แสดงตัวอย่าง `.hwpx` แบบ inline, ค้นหาชื่อไฟล์หลายภาษา (Pinyin / Romaji / Hangul-Hanja)
- **เสริมความสามารถ CJK เพิ่มเติม** (1.3.1): บุ๊กมาร์กอัตโนมัติสำหรับโฟลเดอร์แชต/คลาวด์ (KakaoTalk · LINE · WeChat · iCloud Drive รวม 12 พาธ), การพับความกว้างเต็ม/ครึ่งในการค้นหา, การแปลงการเข้ารหัส EUC-KR/Shift-JIS/GBK → UTF-8 (พร้อมเลิกทำ), การตรวจจับแบบฟอร์มราชการเกาหลีด้วยฮิวริสติก

## ราคา

| | **Free** | **Pro — $24.99** |
|---|---|---|
| เลย์เอาต์บานหน้าต่าง | คู่/สาม/แบ่งอิสระ (ทั้งหมด) | เดี่ยว/คู่/สาม/แบ่งอิสระ |
| เครื่องมือ AI | — | ฟังก์ชัน AI ทั้งหมด |
| การเชื่อมต่อระยะไกล | FTP, SFTP | โปรโตคอลทั้งหมด + คลาวด์ |
| ไฟล์บีบอัด | ZIP | ZIP/7z/TAR/GZ/BZ2/XZ/ZSTD/RAR/**ALZ** |

> **หมายเหตุเรื่องรุ่น** รุ่นจาก Mac App Store ทำงานในแซนด์บ็อกซ์ จึงไม่มีแผง Git, Docker/Kubernetes, อุโมงค์ SSH, เทอร์มินัลในตัว, ตัวดูพอร์ตและโปรเซส หรือการแปลงสื่อที่ใช้ ffmpeg — macOS ไม่อนุญาตที่นั่น ส่วนอื่นเหมือนกันทั้งหมด และ Pro ราคาจ่ายครั้งเดียวเท่ากันทั้งสองทาง หากคุณต้องการสิ่งใดข้างต้น ให้เลือกดาวน์โหลดโดยตรง

จ่ายครั้งเดียว ไม่มีการสมัครสมาชิก ดาวน์โหลดฟรีบน Mac App Store (Pro ผ่านการซื้อในแอป ผูกกับ Apple ID พร้อมการแชร์กันในครอบครัว) หรือดาวน์โหลดโดยตรง (Pro ผ่าน LemonSqueezy ใช้ได้สูงสุด 3 เครื่อง) ทดลองใช้ Pro ฟรี 14 วันเมื่อเปิดครั้งแรก

รายการคุณสมบัติทั้งหมด ทางลัด คู่มือการสร้าง และการพัฒนาปลั๊กอินใน [README ภาษาอังกฤษ](README.md)
