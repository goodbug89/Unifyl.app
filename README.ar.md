## نظرة عامة

Unifyl هو مدير ملفات بنافذتين لنظام macOS يجمع بين أدوات احترافية والذكاء الاصطناعي المحلي على الجهاز. ملفاتك لا تغادر جهاز Mac أبدًا.

- **نافذتان** — تخطيطات بنافذة واحدة/نافذتين/ثلاث/تقسيم حر، علامات تبويب، مساحات عمل، طرفية مدمجة في كل نافذة
- **مدعوم بالذكاء الاصطناعي** — بحث دلالي، إعادة تسمية بالذكاء الاصطناعي، وسم ذكي، اكتشاف المكرَّرات — كلها محلية على Apple Neural Engine
- **عن بُعد وسحابة** — FTP/SFTP/WebDAV/SMB/S3/Google Drive/Dropbox/OneDrive/Docker/Kubernetes
- **أكثر من 50 أداة احترافية** — إعادة تسمية بالدفعات، مقارنة نصوص/ثنائية/صور، مزامنة المجلدات، دمج ثلاثي، محرر EXIF بالدفعات
- **الأرشيف كمجلدات افتراضية** — ZIP/7z/TAR/GZ/BZ2/XZ/ZSTD/RAR (مع كشف ترميز ZIP القديمة لـ CJK)
- **لوحة المفاتيح أولًا** — لوحة الأوامر، تنقل على طريقة Vim، أكثر من 120 اختصارًا قابلًا لإعادة التعيين
- **15 لغة**
- **تعزيز CJK** (1.3.0): استخراج أرشيف `.alz` (`unalz` مدمج)، معاينة `.hwpx` المضمنة، بحث متعدد اللغات لأسماء الملفات (Pinyin / Romaji / Hangul-Hanja)
- **تعزيز CJK الموسّع** (1.3.1): إشارات مرجعية تلقائية لمجلدات المراسلة/التخزين السحابي (KakaoTalk · LINE · WeChat · iCloud Drive — 12 مسارًا)، طي العرض الكامل/النصفي في البحث، تحويل الترميز EUC-KR/Shift-JIS/GBK → UTF-8 (مع التراجع)، كشف ارشادي للنماذج الحكومية الكورية

## السعر

| | **Free** | **Pro — $24.99** |
|---|---|---|
| تخطيطات النوافذ | مزدوج/ثلاثي/تقسيم حر (الكل) | نافذة واحدة/نافذتان/ثلاث/تقسيم حر |
| أدوات الذكاء الاصطناعي | — | جميع وظائف الذكاء الاصطناعي |
| الاتصالات البعيدة | FTP، SFTP | جميع البروتوكولات + السحابة |
| الأرشيف | ZIP | ZIP/7z/TAR/GZ/BZ2/XZ/ZSTD/RAR/**ALZ** |

> **ملاحظة عن الإصدارات.** إصدار Mac App Store يعمل داخل صندوق رملي ولا يتضمّن لوحة Git أو Docker/Kubernetes أو أنفاق SSH أو الطرفية المدمجة أو عارضات المنافذ والعمليات أو تحويل الوسائط المعتمد على ffmpeg — لأن macOS لا يسمح بذلك هناك. كل ما عدا ذلك مطابق، وسعر Pro دفعة واحدة ومتساوٍ في القناتين. اختر التنزيل المباشر إن كنت بحاجة إلى أيٍّ منها.

دفعة واحدة. بدون اشتراك. التنزيل مجاني من Mac App Store (Pro عبر شراء داخل التطبيق، مرتبط بمعرّف Apple مع المشاركة العائلية) أو التنزيل المباشر (Pro عبر LemonSqueezy، يعمل على ما يصل إلى 3 أجهزة). تجربة Pro مجانية لمدة 14 يومًا عند أول تشغيل.

قائمة الميزات الكاملة، الاختصارات، دليل البناء وتطوير الإضافات في [README الإنجليزي](README.md).
