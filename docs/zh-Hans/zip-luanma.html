文件本身没坏,坏的只是名字。老式 Windows 压缩工具用系统代码页 (简体中文是 GBK)记录文件名,而 macOS 按 UTF-8 读取文件名——同一串字节被用错了 解码表,就成了乱码。文件内容完好无损。

恢复正确的文件名

Unifyl 内置了针对这个问题的编码修复功能:选中乱码文件,它会自动检测名字原本是 GBK、Shift-JIS 还是 CP949 编码,先预览恢复后的名字,确认后一键批量 转换。转错了?⌘Z 整批撤销。

  1. 下载 Unifyl 并启动(此功能免费)。
  2. 进入乱码文件所在的文件夹,选中文件。
  3. 运行 Tools ▸ 编码转换 — 预览每个名字将恢复成什么。
  4. 确认即批量转换,支持撤销。

下次让它根本不乱码

别用 macOS 自带的双击解压。在 Unifyl 里按 Return 直接进入 ZIP(压缩包会像文件夹一样打开),把需要的文件用 F5 拷出来——Unifyl 的 ZIP 读取器会在展开时正确判断文件名编码,取出来的名字一开始就是对的。不用全部解压, 也不用清理临时文件夹。
