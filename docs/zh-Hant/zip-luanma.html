檔案本身沒壞,壞的只是名字。舊式 Windows 壓縮工具用系統碼頁 (簡體系統是 GBK)記錄檔名,而 macOS 以 UTF-8 讀取檔名——同一串位元組被套錯了 解碼表,就成了亂碼。檔案內容完好無損。

還原正確的檔名

Unifyl 內建了針對這個問題的編碼修復功能:選取亂碼檔案,它會自動偵測名字原本是 GBK、Shift-JIS 還是 CP949 編碼,先預覽還原後的名字,確認後一鍵批次 轉換。轉錯了?⌘Z 整批復原。

  1. 下載 Unifyl 並啟動(此功能免費)。
  2. 進入亂碼檔案所在的資料夾,選取檔案。
  3. 執行 Tools ▸ 編碼轉換 — 預覽每個名字將還原成什麼。
  4. 確認即批次轉換,支援復原。

下次讓它根本不亂碼

別用 macOS 內建的雙擊解壓。在 Unifyl 裡按 Return 直接進入 ZIP(壓縮檔會像資料夾一樣開啟),把需要的檔案用 F5 拷出來——Unifyl 的 ZIP 讀取器會在展開時正確判斷檔名編碼,取出來的名字一開始就是對的。不用全部解壓, 也不用清理暫存資料夾。
