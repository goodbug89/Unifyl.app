맥에서 HWPX 미리보기 — 한컴오피스 없이

2026년 기준 · "편집은 필요 없고 내용만 보면 되는데요"를 위한 글

메일로 온 공문, 지원사업 안내, 관공서 서식 — 한국에서 일하면 .hwpx는 피할 수 없습니다. 그런데 맥에는 한컴오피스가 기본으로 없고, 파일 하나 열어보자고 유료 오피스를 설치하는 건 과합니다.

선택지 정리

  • 한컴오피스 맥 버전 / 한컴독스 — 편집까지 해야 한다면 결국 이쪽입니다. 유료·계정 필요.
  • 웹 변환 서비스 — 문서를 남의 서버에 올려야 합니다. 회사 문서라면 권장하지 않습니다.
  • Unifyl (이 사이트) — 파일 매니저 안에서 HWPX 내용을 설치도 업로드도 없이 인라인으로 미리봅니다. 무료 기능입니다.

Unifyl에서 HWPX 확인하는 법

  1. Unifyl을 내려받아 실행합니다 (무료).
  2. HWPX 파일이 있는 폴더로 이동합니다.
  3. 파일에 커서를 두고 미리보기를 열면 본문 내용이 바로 표시됩니다.

HWPX는 내부적으로 XML 기반 포맷이라, Unifyl이 문서 구조를 직접 읽어 본문을 렌더링합니다. 문서가 컴퓨터 밖으로 나가지 않습니다 — 변환 서버도, 계정도 없습니다.

한계도 적어두면: 목적은 "읽기"입니다. 복잡한 표·서식은 원본 레이아웃과 다르게 보일 수 있고, 편집은 지원하지 않습니다. 편집까지 필요하면 한컴 제품이 맞습니다.

HWPX가 무더기로 올 때

Unifyl은 파일 매니저라서, 미리보기가 폴더 탐색과 붙어 있다는 게 진짜 장점입니다. 수십 개 서식 파일을 방향키로 넘기며 하나씩 내용을 확인하고, 필요한 것만 F5로 추리는 식의 작업이 빠릅니다. 파일명이 »ç¾÷°ø°í.hwpx처럼 깨져서 왔다면 깨진 한글 파일명 복구부터 하면 됩니다.

Unifyl 무료 다운로드

Unifyl은 macOS 14 이상용 듀얼패인 파일 매니저입니다. HWPX 미리보기, ALZ 해제, 인코딩 복구, 초성 검색이 모두 무료 버전에 포함됩니다. 문의: support@unifyl.app
