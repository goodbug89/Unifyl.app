Unifyl(유니파일)은 전문가용 파워 툴과 로컬 AI 지능을 결합한 macOS 듀얼 패인 파일 관리자입니다. 당신의 파일은 Mac을 떠나지 않습니다.

비교, 동기화, 일괄 이름 변경, 원격 연결 — 구독료는 없습니다.

📁

듀얼 패인 파워

싱글·듀얼·트리플·자유 분할 레이아웃, 탭, 워크스페이스, 드래그 앤 드롭, 그리고 모든 패널에 인라인 터미널까지.

🤖

AI 기반 지능

시맨틱 검색, AI 이름 바꾸기, 스마트 태깅, 중복 탐지 — 모두 Apple Neural Engine에서 로컬로 실행. 설계부터 비공개.

🌐

원격 & 클라우드

FTP, SFTP, WebDAV, SMB, S3, Google Drive, Dropbox, OneDrive 등에 연결. Docker 컨테이너와 Kubernetes 파드도 탐색.

🔍

검색 & 필터

실시간 필터링, 정규식 패턴, 내용 검색, Spotlight 통합. 어떤 파일이든 밀리초 단위로 찾기.

🎨

테마 & 디자인

12개 내장 프리셋, 완전한 테마 편집기, .ultratheme 파일을 통한 커뮤니티 공유. 전체적으로 macOS 네이티브 룩앤필.

⌨

키보드 우선

명령 팔레트, Vim 스타일 네비게이션, 커스터마이즈 가능한 단축키. 마우스에 손대지 않고 모든 작업 접근.

심플하고 정직한 가격.

한 번 결제. 평생 소유. 평생 무료 업데이트.
