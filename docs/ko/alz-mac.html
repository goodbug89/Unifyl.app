Unifyl — macOS 듀얼패인 파일 매니저

맥에서 ALZ 압축 풀기 — 알집 없이 여는 법

2026년 기준 · 한국 파일을 매일 받는 맥 사용자를 위해

회사에서, 관공서에서, 오래된 자료실에서 .alz 파일은 여전히 옵니다. 그리고 macOS의 기본 압축 유틸리티는 ALZ를 모릅니다. 더블클릭하면 "압축을 풀 수 없습니다"가 전부입니다.

선택지 정리

  • 맥용 반디집 — ALZ 해제를 지원하는 무료 앱. 압축 풀기 자체가 목적이면 충분합니다.
  • The Unarchiver — 오래된 무료 해제 도구. ALZ는 파일에 따라 실패하는 경우가 보고됩니다.
  • Unifyl (이 사이트) — 파일 매니저 안에서 ALZ를 폴더처럼 열어서, 전체를 풀지 않고 필요한 파일만 꺼냅니다. 아래에서 설명합니다.

"압축 풀기"보다 나은 방법: 폴더처럼 열기

ALZ로 온 자료에서 실제로 필요한 건 대개 안의 파일 한두 개입니다. Unifyl에서는 ALZ 파일에서 Return을 누르면 압축 파일 안으로 그냥 들어가집니다. 일반 폴더처럼 목록을 보고, 필요한 파일에서 F5를 누르면 반대쪽 패인으로 그 파일만 나옵니다. 전체 해제도, 임시 폴더 정리도 없습니다.

  1. Unifyl을 내려받아 실행합니다 (무료).
  2. 한쪽 패인에서 ALZ 파일로 이동해 Return — 내부 목록이 열립니다.
  3. 필요한 파일을 골라 F5 — 반대쪽 패인의 폴더로 복사됩니다.

같은 방식이 ZIP·7z·TAR·GZ·RAR에도 똑같이 적용됩니다. 압축 형식마다 다른 앱을 쓸 이유가 없어집니다.

참고: ALZ 지원은 unifyl.app에서 받는 직접 다운로드 버전 기준입니다. Mac App Store 버전은 샌드박스 제약으로 ALZ 해제 엔진이 빠져 있으니, ALZ가 목적이라면 직접 다운로드 버전을 받으세요. 같은 무료입니다.

Unifyl 무료 다운로드

Unifyl은 macOS 14 이상에서 동작하는 듀얼패인 파일 매니저입니다. ALZ 해제, HWPX 미리보기, 초성 검색 같은 한국어 특화 기능이 모두 무료 버전에 포함됩니다. 문의: support@unifyl.app
